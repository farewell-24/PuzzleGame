# 拼图工坊 · VS 2026 工程说明

工程位置：`D:\visual studio2026练习\PuzzleGame\PuzzleGame.slnx`
源码：`PuzzleGame\Puzzle.cpp`（内容与你给的代码完全一致，未改任何逻辑）

## 打不开 / 编译不过的两个原因（已修好）

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| `warning C4819` + `error C2059 / C2143 / C2065` | 源文件是 UTF-8 **无 BOM**，中文 Windows 下 MSVC 按代码页 936 解析，中文注释和 `L"…"` 字符串被打散，注释把下一行吃掉 | 源文件另存为 **UTF-8 带签名(BOM)**，并在工程里加 `/utf-8` |
| `LNK2019 无法解析的外部符号 main`（__scrt_common_main_seh 中引用） | 空项目默认 **控制台子系统**，而入口是 `WinMain` | 链接器 → 系统 → 子系统 改成 **窗口 (/SUBSYSTEM:WINDOWS)**，宏 `_CONSOLE` 换成 `_WINDOWS` |

## 本工程当前配置（4 个配置都已改）

- 配置类型：Application（.exe）
- 平台工具集：v145（VS 2026 默认）
- 字符集：Unicode
- C/C++ 语言标准：`stdcpp20`
- 附加选项：`/utf-8`
- 链接器子系统：`Windows`
- 平台：Win32 / x64 均有 Debug、Release

依赖库由源码里的 `#pragma comment(lib, …)` 自动链接：`gdiplus.lib`、`comdlg32.lib`、`gdi32.lib`、`user32.lib`，
**不需要**手动去「附加依赖项」里加。

## 怎么运行

1. 双击 `PuzzleGame.slnx` 打开（VS 2026 新的 .slnx 解决方案格式）
2. 顶部选 `x64` + `Debug`，按 `F5`
3. 界面：左边拼图板，右边控制面板；鼠标拖动任意两块交换位置

## 操作与快捷键

- 拖拽：按住一块拖到另一块松开即交换
- `N` 重新打乱 · `O` 查看原图 · `1/2/3` 切 3×3 / 4×4 / 5×5 · `Esc` 取消操作
- 限时挑战：3×3 给 120 秒，4×4 给 240 秒，5×5 给 420 秒
